## 埋点清单（打分时重点看）

按经验最能区分，从最易错排起：

1. **`NULL = NULL` 返回 TRUE** —— 必须是 UNKNOWN。顺手用 Python 的 `==` 就会错。
2. **`WHERE` 留下了 UNKNOWN 行** —— 只有 TRUE 才留。写成 `if cond:` 会把 None 当假（碰巧对），
   但写成 `if cond is not False:` 就错了。
3. **`sum` 于空集返回 0** —— 必须是 NULL。`sum([])` 在 Python 里是 0，这是最容易漏的一条。
4. **空表上带聚合的查询返回 0 行** —— 必须恰好 1 行。`SELECT count(*) FROM empty` 是 `[[0]]`。
   而 `GROUP BY` 存在时空表返回 0 行。两者必须同时正确。
5. **`bool` 被当成 INT** —— `isinstance(True, int)` 为真，`type_of` 必须先判 bool。
6. **`/` 对两个 INT 返回 INT** —— 规格要求恒为 FLOAT。
7. **除零抛异常** —— 规格要求返回 NULL。
8. **分组按 key 排序** —— 必须按首次出现顺序，不排序。
9. **NULL 在 DESC 下排到最前** —— 规格要求 NULL 恒在最后，DESC 只反转非 NULL。
10. **排序不稳定** —— 必须稳定。多次单键 sort 而不是一次多键比较，容易破坏稳定性。
11. **分组时 NULL 不同组** —— 分组与 DISTINCT 里 NULL 等于 NULL，与 `=` 相反。
12. **`ORDER BY` 里别名没有优先于同名列** —— 别名必须赢。
13. **`WHERE` 能看到别名** —— 不允许；`ORDER BY` 才可以。
14. **`avg` 返回 INT** —— 恒为 FLOAT，且除以非 NULL 计数。
15. **`LEFT JOIN` 在 ON 为 UNKNOWN 时丢掉左行** —— 必须补 NULL 保留。
16. **`1 < 2 < 3` 被接受** —— 比较非结合，必须 ParseError。
17. **`NOT a = b` 解析成 `(NOT a) = b`** —— NOT 比比较松。
18. **`coalesce` 传播 NULL** —— 它是唯一不传播的函数。
19. **`concat` 不传播 NULL** —— 它传播。两者刚好相反，容易写混。
20. **CLI 把单个 NULL 列输出成 `""`** —— 规格要求空字段；用 `csv.writer` 会输出两个引号。
